# Glossary

Use these terms consistently.

- **P/E** — price / earnings; valuation vs profits.
- **P/B** — price / book value.
- **RSI** — Relative Strength Index (0–100); >70 overbought, <30 oversold.
- **MACD** — moving-average convergence/divergence; momentum.
- **SMA50 / SMA200** — 50- and 200-day simple moving averages; trend references.
- **Trailing stop** — a sell trigger set a fixed % below the recent high.
- **Thesis** — the specific reason to own a position; "thesis broken" = that reason failed.
- **Transient vs structural** — temporary, recoverable dip vs a fundamental deterioration.
- **Redeploy** — reinvesting proceeds from a sale into a better use of capital.
